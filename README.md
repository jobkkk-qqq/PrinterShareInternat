# PrinterShare · 打印机共享

基于 **TCP 协议**的 USB/本地打印机共享工具：在主机上运行本服务，局域网内其他电脑就能通过 Windows 自带的"**标准 TCP/IP 端口**"使用主机上的打印机，无需 SMB 共享、无需第三方打印服务器。

- 主机：`PrintShare`（系统托盘常驻）启动后，在 **TCP 9100** 提供原始打印服务，在 **TCP 8081** 提供 Web 管理页。
- 客户端：添加一台 `Standard TCP/IP` 端口打印机，端口填 `主机IP:9100` 即可。

```
┌────────────────┬── 9100 (原始打印数据) ──► ┌───────────────────────┐
│   局域网客户端   │                           │   PrintShare(主机)     │
│  自带TCP/IP端口  │                           │   磁盘暂存队列→串行投递  │
└────────────────┘ ◄──── 8081 (Web管理页) ─── │   WinSpool → 本机打印机 │
                                              └───────────────────────┘
```

## 功能

- **纯 TCP 打印共享**：绕开 SMB 打印共享的各类报错（`0x0000011b`、`0x00000709` 等）。
- **可靠的打印队列**：每个任务流式落盘暂存，同一时刻只向 Windows 打印池投递一个任务；支持排队/打印中/已完成可视化、取消、暂停、优先级、全局暂停，重启后自动恢复未完成任务。
- **Web 管理页**：`http://localhost:8081` —— 选择目标打印机、看队列、生成/复制客户端安装脚本。
- **系统托盘**：开机自启动、暂停/继续队列、查看/复制服务器 IP、清空已完成、退出。
- **单文件 exe**：打包为 portable（便携）exe，复制到任意 Windows 机器双击即用，无需安装。

## 快速开始（使用打包好的 exe）

1. 把编译好的 `PrintShare *.exe` 复制到要当打印服务器的主机（Win 10/11，x64）。
2. 双击运行。**首次会自动弹出一次系统授权窗口**，点「是」后自动放行防火墙（放行 TCP 9100 / 8081）；随后启动服务并出现托盘图标。**只需复制这一个 exe 即可。**
3. 打开管理页 `http://localhost:8081`，在页面里选中这台主机上实际连接的 **目标打印机**。
4. 客户端（局域网其他电脑）添加打印机：
   - 添加打印机 → 选择"**使用 TCP/IP 地址或主机名**"
   - IP/主机名填主机的**局域网 IP**，端口填 **9100**
   - 选择对应的打印机驱动完成添加。
5. 用完后右键托盘图标可随时管理（开机自启动、暂停队列、复制 IP、退出）。

> 更省事的做法：直接在管理页点"**复制客户端安装脚本**"，在客户端以管理员运行生成的脚本即可自动完成端口创建、打印机添加与设为默认。

## 从源码构建 / 运行

需要环境：Node.js ≥ 18。

```bash
# 安装依赖（会自动生成图标）
npm install

# 本地直接跑（开发调试，命令行运行打印服务 + 托盘）
npm start            # 或 npm run electron

# 一键启动脚本（检测 Node、配防火墙、打开管理页）
start-server.bat

# 打包成单文件便携版 exe（输出到 dist\PrintShare *.exe）
npm run build        # 兼容壳：直接运行 build.bat 也可以
```

> `build.bat` 已内置国内网络所需的配置（抓 GitHub 的 nsis 等构建工具会超时，改为走 npmmirror 镜像），并把构建缓存放在项目内 `.buildcache\`，保证一键出包。

## 配置

| 项目 | 说明 | 默认 |
| --- | --- | --- |
| `RAW_PORT` | 客户端打印连接端口（环境变量） | `9100` |
| `ADMIN_PORT` | Web 管理页端口（环境变量） | `8081` |
| `config.json` | 目标打印机名（首次运行自动创建，非必需） | 自动取默认打印机 |
| `queue/` | 磁盘暂存的任务队列；`meta.json` 存元数据 | 自动创建 |

通用 DryRun（仅走队列流程、不真正打印，用于联调）：
```bash
set DRYRUN=1   # 然后 node server.js
```

## 目录结构

```
main.js            Electron 主进程：托盘菜单 + 开机自启动 + 启动服务
server.js          核心打印服务：TCP 9100 收流 → 磁盘队列 → 串行投递 → WinSpool
winspool.ps1       PowerShell P/Invoke，把数据交给本机打印机（零原生依赖）
public/index.html  Web 管理页：打印机选择、队列可视化、客户端脚本生成
make-icon.js       生成托盘/应用图标（ico/png）
build.bat          一键打包脚本（内置镜像与缓存路径）
start-server.bat   一键启动脚本（检测 Node、放行防火墙、打开管理页）
```

## 常见问题

- **客户端显示脱机 / 打不开管理页**：确认主机已放行 `TCP 9100` 与 `8081`。便携 exe 首次启动会自动弹 UAC 放行；若点过「否」或换过端口，可右键 `start-server.bat` 以管理员运行补放行。
- **端口被占**：管理页默认用 8081（若被占则用 `ADMIN_PORT` 换）／打印端口 9100（被占则用 `RAW_PORT` 换）。
- **开机自启动复选框没效果/不亮**：复选框状态来自注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 的值 `PrintShare`，漏勾时手动加回即可；必须是便携版 exe 路径，不能是解压到临时目录的路径（代码已自动处理）。
